# Codalith brand assets

The mark combines three geometric source strata into an open C, with a jade terminal square. It represents stable source evidence and immutable generations.

| Asset | Size | Format | Use |

| `codalith-mark.png` | 1254 × 1254 | RGBA PNG | App icon, favicon source, compact brand mark |
| `codalith-logo.png` | 2172 × 724 | RGBA PNG | README and documentation header |
| `codalith-logo-dark.png` | 2172 × 724 | RGBA PNG | GitHub dark-theme README and dark surfaces |

All files have transparent alpha backgrounds. Preserve the proportions and leave clear space around the symbol. Use the forest-green logo on a light or warm-white surface; use the near-white logo on dark surfaces. A README can switch between the two horizontal logos using a `picture` element with `prefers-color-scheme`.

- Body and wordmark: forest green, target `#153d36`.
- Dark-theme body and wordmark: soft near-white, target `#e7f1eb`.
- Accent: jade green, target `#38b996`.
- Exact brand spelling: **Codalith**.

Generated with the built-in image generation tool on 2026-10-23. The horizontal logo uses the mark as its identity reference. The PNGs were copied directly from the generated outputs; no scripted image editing was applied.
